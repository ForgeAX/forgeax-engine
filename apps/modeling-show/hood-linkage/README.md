# C-116 hood four-bar

turntable; the u slider drives its scene's AnimationPlayer through the cylinder's full stroke.

Show controls as `../README.md`.

Its Pack exists from forgeax-modeling main 3e86348 on, ahead of the Engine pin, so the app
tsconfig leaves this project out until the pin passes it; the runner builds it on modeling main.
