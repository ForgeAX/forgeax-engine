# maid-whale

The F2 (case C-200) low-poly character on the Show turntable: the G6 faceted mesh of
forgeax-modeling `examples/maid-whale`, colored from the reference sheet palette. It is the
`f2` (modeling main) and `f2-wip` (the builder's branch) subject of the interactive 3D pages
(`../scripts/show-rebuild.mjs`). Same Show controls as `../README.md`; the Facet edges view
draws the faceting.
