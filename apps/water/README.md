# Water demonstration suite

The gallery discovers seven applications: the combined R0–R2 island watershed,
R3 optics, the combined R4–R5 boat experience, R6 local fluid, R7 advanced water,
R8 entry experiment, and the independent integrated coast showcase.
Each formal entry owns one World and scene. R7 retains shallow, River Bake
and Ocean views inside its shared Renderer. The combined watershed embeds
Scene/Zone lifecycle, authored Body geometry, TerrainProvider, WaterMesh,
WaterInfo, Gerstner and query controls in one large lake-to-river-to-sea world.

Run the desired workspace's `dev` command. Runtime panels follow mounted
entities, show accepted source values and expose stage-specific operations.
Immutable identities and cooked facts remain read-only. Completed ready-frame
telemetry excludes unavailable presentations. The integrated showcase adds four
workload presets, native inertial WASD/arrows navigation and Space thrust boost.
Collapsed parameter sections do no periodic asset reads unless an edit is awaiting
acceptance. Opening a section refreshes it immediately; each demanded refresh
shares one detached source observation across its fields. Native pending values
remain visible until commit or the owner's explicit rejection restores accepted data.
Stage binding reconciliation tracks mounted identity and admission policy; source
branch changes are reconciled by the demanded form observation. Static material
switches are publication facts in these shared panels, while runtime values use
the accepted material update owner.

The dedicated R8 entry experiment covers native residuals and the independent
v2 visual-normal FFT. The original integrated coast remains a separate showcase.
The combined world replaces the earlier R0/R1 museum presentation.
R6 and R7 use the same laboratory architecture with authored textured basin
beds, gauge assemblies and closer station framing. These presentation assets
leave the stage's geometry, query and simulation ownership intact.

Development servers enable the existing App RHI recorder. Set
`FORGEAX_RHI_CAPTURE_ROOT` to an external directory for tape uploads. See the
application README and the owning [Water contract](../../packages/water/README.md)
for operation details. Validation narratives belong in the Harness Water docs;
raw screenshots, timings and tapes stay outside the source checkout.
