# R0 Scene foundation

Run `pnpm dev` and open port 5380. This dedicated root exercises actual Water
asset admission, Body instance mount/retirement, source replacement and shared
Zone binding. The illuminated museum room and limestone/brass platforms are supporting presentation;
R0 does not claim later Water rendering, geometry, query or simulation products.
The runtime panel and `window.__waterR0` expose accepted source/generation facts.

See [Water ownership](../../../packages/water/README.md).
