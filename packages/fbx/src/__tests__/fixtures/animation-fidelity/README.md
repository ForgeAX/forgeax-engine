# FBX source curve regression fixtures

The two FBX inputs originate from the MIT-licensed ufbx 0.23.0 test data: `maya_anim_interpolation_7700_ascii.fbx` and `maya_game_sausage_7500_ascii_spin.fbx`. Their filenames here are shortened. The adjacent oracle JSON files contain original `ufbx_evaluate_transform` samples at non-keyframe times, generated by `packages/fbx/scripts/animation-oracle.c`; they are independent of `ufbx_bake_anim` and the Engine sampler.

The runtime regression parses the real FBX through the native WASM producer, converts through JSON and the ordinary AnimationClip loader, and compares ECS poses with this frozen source oracle. Euclidean translation, unit-quaternion angular error and scale errors use the budgets declared in the test.
